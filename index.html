About My Garden

Start with the garden you have today. Make a simple map of the space you want to think about during this course. It does not need to be beautiful or perfectly to scale—we just need a useful starting point.

1. Set the scene

Choose any space that is useful to you: a yard, garden bed, patio, balcony, community garden plot, or another growing space.

For now, record what is already there. You do not need to make it more climate-resilient yet. You will return to this map later with more tools and ideas.

2. Map what is there now

Select the item you wish to place. Click or tap inside the garden to add it. You can name it on the right-hand side under Label to identify the object. Select an item to move, resize, or rotate it. Measurements update as you resize.

If something in your garden has an unusual shape, choose Custom shape, click around its outline, then choose Finish shape. You can label and edit it just like the other features.

For a path, click several points to show where it bends, then double-click or press Enter to finish. For a custom shape, use Finish shape when its outline is complete.
